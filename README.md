# 夜市合合乐

一款使用原生 JavaScript 与 HTML Canvas 制作的原创合成小游戏，可直接部署到 GitHub Pages。

## 本地运行

用任意静态服务器打开 `dist` 目录。例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 <http://localhost:4173>。

## 发布到 GitHub Pages

项目已包含 GitHub Pages 自动发布流程。把 `夜市合合乐` 作为仓库根目录推送到 `main` 分支，然后在仓库的 **Settings → Pages → Source** 中选择 **GitHub Actions**；后续每次推送都会自动发布 `dist`。

## 玩法

- 点击蒸笼铺、面点铺、烧烤炉，分别产出米食、面食和烧烤原料。
- 同菜系、同等级的两个食材可以升级；第 3 级解锁茶饮甜品链。
- 凑齐订单后点击订单卡片领取金币与声望。
- 组合订单会同时要求多个菜系；制作复杂度由关卡和轮次决定，倒计时按原料量保底。
- 食客订单带倒计时；超时会损失耐心并在棋盘生成垃圾。
- 18 秒内连续交单可以叠加连击倍率，贵客订单时间更紧、收益更高。
- 每完成 7 次合成会产出百搭酱，可替代同等级任意菜系完成合成。
- 每关两轮，每轮目标分别为 6 / 7 / 8 单。第一轮后从三张随机能力卡中选一张；第二轮结束结算星级。
- 三星条件：通关、零超时、零超时且本局达到三连单。每关保存最高星级和最高通关分数。
- “救场”首次消耗 30 金币，每用一次下次加价 20；为全部订单增加 12 秒并清除摊位冷却。
- 每局两次拆分食材、一次免费更换最紧急订单；可出售不需要的食材腾出格子。
- 营业时每三秒恢复一点体力，交单也有补给；主页和所有弹窗都会暂停。
- 工坊有炉灶、座席、补给三条永久升级路线，各三等级。失败与重开会保留金币、等级、收藏、升级和关卡记录。
- 四条菜系共 24 个收藏位，第一次获得新食材自动奖励金币；旧存档中现存食材计入收藏，不重复发奖。
- 打开游戏先进入掌柜主页，可查看三步玩法、菜谱、当前档案并控制背景音乐与音效。
- 包含三种真实难度关卡：长街初灯、雨夜客潮和灯会之夜；目标数量、订单速度、贵客概率、耐心与初始垃圾均不同。
- 在同一局完成两轮即可通关并解锁下一关。换关会重建棋盘并重置本局进度，提前显示确认。
- 游戏进度会保存在当前浏览器。

背景插画由 OpenAI 图像生成工具为本项目原创生成。

## 验证

从项目目录运行 `node --test tests/game.test.cjs`。测试使用隔离存档，覆盖通关、暂停、升级、收藏、订单可达性、拆分、失败恢复与完整交单流程。浏览器中另检查了桌面和 390×844 布局、工坊、图鉴及拆分操作。

## 玩法研究

参考 [Travel Town 官方棋盘说明](https://support.traveltowngame.com/hc/en-us/articles/4833664499090-The-Merge-Board) 中的交单建设循环和首次发现奖励，以及 [PlateUp! 官方更新](https://www.plateupgame.com/updates/1-4-0-buffet/) 中影响经营难度与收益的选择。本项目将这些思路改编为永久工坊、收藏和轮间能力选择，没有使用原游戏素材。

目前为本地存档的单人原型，尚无真实玩家留存数据。接下来适合用试玩记录验证首关通关率、不同能力的选择比例与平均单局时长，再调整数值。
