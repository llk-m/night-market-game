# 夜市合合乐 · 小店养成版

使用原生 JavaScript、HTML Canvas 和 Web Audio 制作的原创夜市经营小游戏，可部署到 GitHub Pages。

## 三步玩法

1. 点蒸笼铺、面点铺、烧烤炉，免费领取食材。
2. 点两份相同食材（或拖动到一起），合成更高级的美食。
3. 点做好的订单领金币，用金币扩建小店、买装饰。

订单不限时、不耗体力、没有耐心或失败结算，也不会做完两轮就结束。点击订单可查看备菜路线；“免费换单”更换当前追踪的未完成订单，“找合成”标出可合成食材。摊位有约半秒的备料间隔，避免误触连点。

## 长期成长

扩建需要同时达到累计招待数量，并支付金币。扩建不会清空棋盘、现有食单和收藏。

| 店铺等级 | 店铺名称 | 累计食客 | 扩建金币 |
| --- | --- | ---: | ---: |
| 1 | 街角小摊 | 0 | 0 |
| 2 | 灯下食铺 | 8 | 280 |
| 3 | 巷口茶食 | 22 | 700 |
| 4 | 邻里小馆 | 45 | 1400 |
| 5 | 花间食堂 | 80 | 2400 |
| 6 | 庭院餐馆 | 130 | 3800 |
| 7 | 长街名店 | 200 | 5800 |
| 8 | 烟火老字号 | 300 | 9000 |
| 9 | 四季食府 | 430 | 14000 |
| 10 | 夜市地标 | 600 | 21000 |

- 店铺 3 级解锁茶饮铺；已在旧版解锁的茶饮会保留。
- 随店铺等级解锁更高级的菜品订单；始终保留一个简单订单位置。最高店铺等级后仍可继续经营。
- 有 8 件可购买的装饰，买下自动摆在首页。店铺成长会改变棚顶，并逐步增加窗台和庭院。
- 四位常客随店铺等级来访，招待次数永久积累；每人每来 5 次自动送 80 金币，最多显示 5 颗好感心。
- 每完成 10 个订单自动送 120 金币；奖励无需手动领取。
- 四条菜系共 24 种美食，首次发现奖励金币。
- 工坊是可选升级：炉灶缩短备料间隔，座席增加订单收入，精选原料提高直接产出二级食材的概率。旧版工坊等级保留，并使用新效果。
- 不需要的食材可以出售，下一次经营操作前可撤销。

## 存档迁移

养成版使用本机浏览器存档键 `nightMarketMergeSave_cozy_v1`。首次运行会读取旧版 v3 / v2 / v1 存档，保留金币、食材、菜谱、工坊等级、音乐偏好和旧关卡记录；清除失败状态、轮间选牌和垃圾，换成不限时订单。历史招待数量根据旧版已记录的交单和轮次推算。

旧存档键原样保留，不删除。新存档会在操作后自动保存。进度属于当前浏览器和网址，不会自动在电脑、手机或不同网址之间同步。

## 音乐

点击首页右上角“点我听”或进入营业，启动原创《夜市小调》。旋律、低音、分解伴奏与轻节拍由 Web Audio 在本机合成，无需下载音频。背景音乐和操作音效可以独立开关，音乐音量和偏好自动保存；切到后台停止音乐。

背景插画由 OpenAI 图像生成工具为本项目原创生成，店铺装饰、纸质食单和棋盘使用 HTML/CSS/Canvas 绘制。

## 本地运行

在项目目录运行：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 <http://localhost:4173>。

## 发布到 GitHub Pages

把“夜市合合乐”作为仓库根目录，仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。推送到 `main` 后自动发布 `dist`：

```powershell
git add .
git commit -m "改为小店养成版"
git push
```

## 验证

运行 `node --test tests/*.test.cjs`。隔离测试覆盖不限时订单、免费产出、扩建门槛、茶饮解锁、装修存档、老存档迁移、常客和十单奖励防重复、换单、点选合成、满棋盘保护和音乐开关。

长流程测试模拟 1,000 次交单，确认店铺能够成长到最高等级且之后仍可继续经营。此测试验证逻辑和经济可达性，不代表已经测量真实玩家的成长时长。浏览器另验证了首次合成、交单、买装饰、刷新保留以及手机布局。
